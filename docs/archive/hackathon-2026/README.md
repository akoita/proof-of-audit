# Hackathon archive (Synthesis, March 2026)

These documents were written for the Synthesis hackathon submission
(build window ended 2026-03-22): judge briefs, evaluation indexes,
pitch scripts, submission packs, and demo narratives. They are kept
for historical context and are **not maintained** — several describe
mechanisms that have since changed (e.g. the retired benchmark
auto-resolution) or make claims scoped to the hackathon demo.

For the current product direction, start at
[docs/strategy/](../../strategy/) — the vision, product strategy,
roadmap, and technology radar that superseded this material in July 2026.
